# Glint 1.0.0

Glint 1.0.0 is the first release: a native macOS action bar for selected text.

## What it does
- **Bar on selection:** select text in any app and a floating bar appears next to it. It works after a drag, a double- or triple-click, a shift-click or a keyboard selection, and a long press in a text field gives a Paste bar. A global shortcut shows the bar on demand, and each action can have its own shortcut.
- **Built-in actions:** Search, Cut, Copy (⇧ appends), Paste, Paste and Match Style, Open Link(s), New Email, Call, Reveal in Finder, Look Up, Spelling suggestions, Bold/Italic/Underline, Speak, Word Count and Calculate. Selecting an extension snippet offers Install Extension.
- **28 bundled extensions:** Translate, Change Case, Sort Lines, Format JSON, Base64, hashes, URL encode/decode, Markdown link, Reminders, Notes, Open in Terminal, Run Shortcut, and web searches including Wikipedia, YouTube, Maps, GitHub, Stack Overflow, Claude and Perplexity.
- **Extensions:** write them as YAML or JSON configs, snippets, shell scripts in any language, AppleScript, JavaScript (including `fetch` and `axios`), key combos, Services or Shortcuts. Glint also accepts the PopClip snippet and `.popclipext` formats. `docs/EXTENSIONS.md` is the full reference.
- **Settings:** activation, appearance (icons or text, three sizes, light/dark), drag-to-reorder actions, per-extension options (secrets go to the Keychain), excluded apps, and launch at login.
- **Safety:** your clipboard is always restored, and slow results never paste into the wrong place. Untrusted extension configs are read in a sandboxed helper process, and no extension code runs before you confirm an install.

## Install
1. Download `Glint.zip`, unzip it, and move **Glint.app** to `/Applications`.
2. Open Glint. It lives in the menu bar.
3. Grant **Accessibility** when asked (System Settings → Privacy & Security → Accessibility).

This build is signed with an Apple Development certificate and isn't notarized. On a Mac other than the build machine, open it the first time with right-click → Open, or run `xattr -dr com.apple.quarantine /Applications/Glint.app`.

## Quality
- Core tests: 105, all passing. They cover the extension engine, script runners, the JavaScript API and the bundled extensions.
- Live checks on macOS: in-place transforms with clipboard restore, Calculate, the spelling fix, long-press Paste, snippet install and reinstall, and hover labels.
- 31 rounds of independent code review (Opus 5.5 and Fable 5.2). All findings are fixed; the final round found one low-severity item.
