# Glint 1.1.0

## Highlights

Glint 1.1.0 is the first release built and published by GitHub Actions. It is a universal app (Apple silicon and Intel) and it checks for updates itself. Selecting text, the bar and the extension engine work as they did in 1.0.0.

## Update checks

Once a day Glint asks GitHub for the latest release. When a newer one exists, the menu bar menu shows **Update Available** and Settings → About shows a **Download** button. Choose **Check for Updates…** in the menu bar menu to check right away. To turn the daily check off, go to Settings → General → **Check for updates automatically**. The request goes to GitHub's public releases API and nothing else is sent. Glint only ever opens release pages of this repository.

## Universal, ad-hoc signed builds

Releases are now built on GitHub's macOS runners from the tagged commit. Each one ships as `Glint-<version>-macos-universal.zip` with a `SHA256SUMS.txt`. The app is ad-hoc signed rather than notarized, so the first launch needs one approval in **System Settings → Privacy & Security → Open Anyway**.

macOS ties the Accessibility permission to the app's signature, and an ad-hoc signature changes with every build. **After updating, re-enable Glint in System Settings → Privacy & Security → Accessibility.** If the switch already looks on but the bar doesn't appear, remove Glint from the list with **−** and add it again.

## Website

Glint now has a website at https://saibarathr.github.io/glint/. It has downloads, install steps, a demo, an extension gallery with one-click installs, and the full guide to writing extensions.

## For developers

- `scripts/build-app.sh` replaces `scripts/build.sh`. It builds a universal ad-hoc-signed app; `--native` builds one architecture, `--dev-sign` signs with your Apple Development identity so Accessibility survives rebuilds, and `--install` copies the app to Applications.
- CI runs the engine tests, builds the universal app, checks its signature and architectures, renders the UI headlessly, and checks the out-of-process config reader.
- See `docs/releasing.md` for how a release is made.

## Install

Download `Glint-1.1.0-macos-universal.zip` and `SHA256SUMS.txt`, then check the archive:

```bash
shasum -a 256 -c SHA256SUMS.txt
```

Unzip it and move `Glint.app` to Applications. Open it once, then click **Open Anyway** in **System Settings → Privacy & Security** and allow Glint under **Accessibility**. Glint needs macOS 14 or newer.
