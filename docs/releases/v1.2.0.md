# Glint 1.2.0

## Highlights

Glint has a new icon: a light action bar over an amber text selection on a charcoal tile. It uses the same mark as the website. Selecting text, the bar and the extension engine work as they did in 1.1.0.

## Website and extension gallery

The website at https://saibarathr.github.io/glint/ is now live. It has:

- downloads and install steps;
- an extension gallery where you copy a snippet or download a package;
- the full guide to writing extensions;
- a page listing the safety limits every action runs under.

## Docs

- The action kinds table in `docs/EXTENSIONS.md` renders correctly again; the AppleScript note now sits below it.
- `docs/EXTENSIONS.md` links to the Safety and limits page.

## For developers

- `scripts/make-icon.swift` draws the new icon in solid colours.
- CI now also runs when only the gallery or the website changes, so the gallery tests always run.

## Install

Download `Glint-1.2.0-macos-universal.zip` and `SHA256SUMS.txt`, then check the archive:

```bash
shasum -a 256 -c SHA256SUMS.txt
```

Unzip it and move `Glint.app` to Applications. Open it once, then click **Open Anyway** in **System Settings → Privacy & Security** and allow Glint under **Accessibility**. Glint needs macOS 14 or newer.

The app is ad-hoc signed, and macOS ties the Accessibility permission to the signature. **After updating, re-enable Glint in System Settings → Privacy & Security → Accessibility.** If the switch already looks on but the bar doesn't appear, remove Glint from the list with **−** and add it again.

If the Dock or Finder still shows the old icon after updating, that is macOS's icon cache; it refreshes after a restart.
